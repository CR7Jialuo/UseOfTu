# 使用说明（交作业前看这一页）

## 一、目录里有什么

```
bin/nav.exe        命令行版（Windows x64，静态链接）
bin/navgui.exe     图形版
data/campus_real/  真实路网（353 节点 / 409 道路）+ 底图
data/campus/       示意数据（24 地点 / 41 道路，测试用）
docs/              报告、PPT、图表
src/ include/ gui/ 源码
scripts/           构建与测试脚本
```

## 一、首次运行先做这一步（SmartScreen）

从网上下载或解压后直接双击 `navgui.exe`，可能弹「Windows 已保护你的电脑」。这是 SmartScreen 对
**带网络来源标记的未签名程序**的例行拦截，不是程序有问题。

**推荐做法**：双击 `第一次运行.bat`（或 `run_gui.cmd`）。它们会把 exe 复制到
`%LOCALAPPDATA%\CampusNav\` 再启动——重写字节会丢掉网络标记，所以不再弹窗。

其他方式：右键 exe → 属性 → 勾选“解除锁定”；或点「更多信息」→「仍要运行」。
程序没有代码签名证书，无法从代码层面彻底去掉这个提示，但用上面的启动方式就不会再遇到。

## 二、直接运行

**推荐双击 `run_gui.cmd`**（源码目录和解压后的提交包都能用）：它会自动找到
`bin\navgui.exe`（提交包内）或 `build\navgui.exe`（源码目录），复制成不带网络标记的干净副本再启动，
同时把 `--data` 指到 `data\campus_real`。

也可以直接双击 `bin\navgui.exe`，但那样可能触发 SmartScreen（见上一节）。

图形界面操作：

- 滚轮缩放、按住拖动平移
- 单击地点选中，按 `1` 设为起点、`2` 设为终点，`Enter` 规划
- `+` / `-` 缩放，`Home` 适应窗口，方向键平移，`空格` 重播动画，`Esc` 清除
- 右击地点添加途经点（带编号），按 `T` 规划多点巡游
- 菜单「文件 → 导出当前视图(PNG)」可把当前画面存成图片

## 三、命令行常用命令

```bat
cd /d <解压目录>
bin\nav.exe --data data\campus_real check
bin\nav.exe --data data\campus_real route 1 5
bin\nav.exe --data data\campus_real route 18 6 --by time
bin\nav.exe --data data\campus_real near 3 canteen
bin\nav.exe --data data\campus_real critical
bin\nav.exe --data data\campus_real mst
```

地点编号：1 号门(1)、图书馆(5)、学生公寓A区(18)、文达楼(6) 等，
用 `bin\nav.exe --data data\campus_real spots` 可列出全部 20 个地点。

## 四、自己重新编译（可选）

需要 MinGW-w64（gcc 在 PATH 中）：

```bat
build.cmd          :: 命令行版 -> build\nav.exe
build_gui.cmd      :: 图形版   -> build\navgui.exe
test.cmd           :: 单元测试（1592 项断言）
```

## 五、验证过的事实

- `check`：353 个地点、409 条道路、路网连通、141 个割点、190 条桥
- `route 1 5`：1号门 → 图书馆，1114.6 米、约 22.3 分钟
- `route 18 6`：学生公寓A区 → 文达楼，1127.3 米、约 22.5 分钟
- 单元测试 22 组 1592 项断言全部通过
- 图形界面离屏渲染与自检均通过（CI 的 Windows 作业也会跑）
